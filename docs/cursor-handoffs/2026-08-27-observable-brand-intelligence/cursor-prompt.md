- Do not push, deploy, publish, change GitHub settings, change Vercel, mutate PostHog, or touch production data.

## Completion protocol

1. Run every required acceptance command that is feasible locally.
2. Populate `cursor-handback.md` with exact commits, files, commands, counts, evidence paths, and risks.
3. Leave the branch ready for independent Codex review.
4. Print a concise final report naming completed work orders, failed or skipped checks, current Git status, and the handback path.

Completion means the code and evidence are ready for Codex acceptance. It does not mean the project is approved, pushed, deployed, or production-ready.
